# 金沢大学 LMS 課題チェッカー

アカンサスポータルの最初の画面上部に、WebClassの課題・提出期限を科目別の表で表示するGoogle Chrome拡張機能です。

## 主な機能

- 学務情報サービスの「履修時間割表」を正本として、現在のクォーターの履修科目だけを取得
- 「科目種別」を順番に確認し、共通教育・専門教育等の対象科目を統合
- 時間割表上の正式な科目名を使用
- 時間割番号と科目名を別々に解析し、一覧には科目名だけを表示
- ログイン中の時間割ページから科目詳細HTMLを読み、SSOリンク内のWebClass `courseId`を取得
- 教材一覧の「レポート」「自習」から項目名と利用可能期間を取得
- 左端のチェックボックスで各課題の完了状態を自分で記録（状態はChrome内に保存）
- 期限が近いものから並べ、未完了で期限を超過した課題の行を薄い赤色で表示（完了チェック時は白色）
- 利用可能期間の終了まで2日以内の未完了課題を薄い黄色で表示（完了チェック時は白色）
- 完了チェックを付けたときにチェックマークのポップアニメーションを表示
- 完了チェックの状態に関係なく、利用可能期間の終了日時が早い順に表示
- 利用可能期間の欄は終了日時を「月・日・時刻」だけで表示
- 期限前の課題は日数制限なしで表示し、期限切れの課題は直近3日分だけ表示
- 各課題の「非表示」ボタンと、保存した非表示設定を解除する「非表示をすべて戻す」ボタン
- 課題を非表示にする前に確認画面を表示
- 「非表示」ボタンはカーソルを合わせると赤色に変化
- アカンサスポータル上の課題表フッターに拡張機能バージョンを表示
- 課題表をワンタッチで収納・再表示（初期状態は収納）
- アカンサスポータルのヘッダーを課題表より上に固定
- 表から各科目・課題を直接開く
- 取得結果をChromeのローカルストレージだけに保存（外部サーバーへの送信なし）

## インストール方法

1. このフォルダーを任意の場所へ置きます。ZIP版を使う場合は、先に展開してください。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. この `kanazawa-lms-deadlines` フォルダーを選びます。

## 使い方

1. 金沢大学IDでアカンサスポータルへログインします。
2. `https://acanthus.cis.kanazawa-u.ac.jp/base/top/` を開きます。
3. 画面上部の「課題・提出期限」で「時間割を取得」を押します。
4. 学務情報サービスで「履修・成績情報」→「履修時間割表」を開きます。
5. 初回だけ、時間割から任意の科目を通常操作で開き「ジャンプ」を押して、WebClassの教材一覧までログインします。
6. WebClassのウインドウとタブをすべて閉じます（WebClassは複数コースの同時利用を許可していません）。
7. 履修時間割表へ戻り、右下の「金沢大学 LMS 課題チェッカー」で「現在のQを取り込む」を押します。
8. 現在のクォーターと各科目種別が1科目ずつ確認され、取り込み完了後にポータルの課題表が更新されます。

バージョン1.12.0以降へ更新した直後は、以前の誤った時間割・LMSリンクのキャッシュを使用しないため、必ず一度「現在のQを取り込む」を実行してください。通常操作で最初の科目を開いて大学のSSO認証を済ませた後、拡張機能は時間割から取得した各科目固有の「LMS（ジャンプ）」URLを1つずつ開きます。科目ごとに異なる `acs_` は保存も使い回しもしません。取得タブを閉じ終えてから次の科目へ進みます。

以後はポータル上の「LMSを更新」で、取り込んだ現在クォーターの科目だけを更新できます。クォーターが変わったときは、もう一度「時間割を取得」を行ってください。

一度取得した結果は保存され、次回はすぐに表が表示されます。10分以上経過したデータは、ポータルを開いたときに自動更新します。過去クォーターの保存データは表示対象になりません。

## 完了チェックと期限について

- 提出・実施済みかどうかは自動判定せず、一覧左端のチェックボックスで自分で記録します。
- チェック状態は課題ごとにChrome内へ保存され、LMS更新後も維持されます。
- 期限を取得できない課題は、期限による表示範囲を判定できないため一覧には表示しません。
- 公開期間が終了してWebClassから非表示になった課題は取得できない場合があります。

この表は確認を補助するものです。重要な提出は、必ずWebClassの各課題画面でも最終確認してください。

## プライバシー

拡張機能がアクセスするのは `*.kanazawa-u.ac.jp` のHTTPSページだけです。取得した科目名、課題名、期限と、自分で設定した完了チェックはChrome内に保存され、開発者を含む外部への送信機能はありません。

## ファイル構成

- `manifest.json` — Manifest V3設定
- `background.js` / `resolver.html` / `resolver.js` — ログイン状態を引き継いだLMSページ取得
- `parser.js` — WebClassの科目・課題・期限・提出状況の解析
- `portal.js` / `portal.css` — ポータル上の表と更新処理
- `timetable-capture.js` / `timetable.css` — 履修時間割表の現在クォーター取得
- `lms-capture.js` — WebClassを通常閲覧した際のデータ補完
- `popup.html` / `popup.js` / `popup.css` — 拡張機能ボタンの画面

## 対応範囲

WebClass 12系の画面構造に対応しています。WebClassやアカンサスポータルの更新でHTML構造が大きく変わった場合は、`parser.js` のセレクター調整が必要になることがあります。
